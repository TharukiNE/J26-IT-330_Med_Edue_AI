# J26-IT-330_Med_Edue_AI
## Project Overview
Med_Edue_AI is a proposed AI-powered educational support platform for medical education. It brings together student engagement monitoring, degree-specific AI tutoring, personalized learning recommendations, and academic performance prediction to support students and educators.This repository contains the collaborative final-year research project for J26-IT-330.

## Main Research Components
1. IoT-Based Student Engagement Monitoring
2. Degree-Specific RAG AI Tutor
3. Explainable Personalized Learning Recommendations
4. Academic Performance Prediction
